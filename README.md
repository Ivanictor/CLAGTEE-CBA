# Guia dos Notebooks

Os notebooks se organizam da seguinte forma:

`main.ipynb`: Contém o estudo principal em todos os casos de análise selecionados <br>
`battery.ipynb`: Faz as análises necessárias (SOC, fluxo de carga) para a criação dos arquivos DSS das baterias <br>
`peakshave.ipynb`: Teste para futuros estudos, implementa as baterias no modo Peak Shaving ao invés do modo Follow <br>
`map_and_loads.ipynb`: Possui mapas de visualização básica e um dataframe com as cargas
